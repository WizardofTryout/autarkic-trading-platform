# Autarkic Trading Platform (December 2025)

This project is a self-hosted, AI-driven crypto trading platform designed for digital sovereignty ("Autarky"). It allows users to develop, test, and execute trading strategies (Pine Script) without relying on external cloud providers like TradingView.

## 🏗 Project Structure

The project follows a **Microservices Architecture** orchestrated via Docker Compose.

| Service | Path | Description |
| :--- | :--- | :--- |
| **Frontend** | `/frontend` | **React 18 + Vite + TailwindCSS v4**. The user interface for charting, strategy management, and trading. Uses **D3.js** for rendering financial charts. |
| **Backend** | `/backend` | **FastAPI (Python 3.11)**. The core API handling authentication, market data, and strategy execution. Uses **SQLAlchemy** (Async) and **Pydantic**. |
| **Strategy Engine** | `/strategy-engine` | **Python**. Dedicated service for executing trading logic. Includes a **Pine Script Transpiler** to convert Pine Script into executable Python code (`pandas_ta`). |
| **Infrastructure** | `/infra` | Contains `docker-compose.yml`, environment configurations, and database setups (TimescaleDB, Redis). |

## 🐳 Docker Architecture & "Docker First" Policy

This project enforces a strict **Docker First** development policy to ensure consistency across environments.

### Services & Networking
-   **`public_net`**: Exposes Frontend (`5173`) and Backend (`8000`) to the host.
-   **`app_net`**: Internal communication between Backend, Strategy Engine, and Redis.
-   **`data_net`**: Isolated network for Database (TimescaleDB) and Redis.

### Development Workflow
**CRITICAL**: All dependencies and commands must be executed **inside** the containers.

-   **Start Project**:
    ```bash
    cd infra
    docker-compose up -d
    ```
-   **Install Frontend Dependencies**:
    ```bash
    docker exec -it frontend npm install <package_name>
    ```
-   **Install Backend Dependencies**:
    ```bash
    docker exec -it backend pip install <package_name>
    ```
    *(Note: Rebuild the container after adding Python dependencies to persist them)*

## 🚀 Key Features (Current Status)

### 1. Pine Script Editor & Transpiler
-   **Integrated Editor**: CodeMirror-based editor with syntax highlighting and line numbers.
-   **Native Execution**: Pine Scripts are transpiled to Python and executed locally.
-   **Visual Feedback**: Buy/Sell signals generated by the script are automatically visualized on the D3 chart.

### 2. Advanced Charting
-   **D3.js Implementation**: Custom-built financial chart replacing TradingView widgets.
-   **Indicators**: Built-in support for RSI, MACD, Bollinger Bands, SMA, and EMA.
-   **Performance**: Optimized for handling real-time crypto market data.

### 3. Architecture
-   **Mock Data Mode**: Currently runs on synthetic data for testing execution flows.
-   **In-Memory Storage**: Temporary storage for custom strategies (persists until restart).

## 🛠 Getting Started

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/WizardofTryout/autarkic-trading-platform.git
    cd autarkic-trading-platform
    ```

2.  **Environment Setup**:
    -   Navigate to `/infra`.
    -   Ensure `.env` exists (copy from `.env.example` if available).

3.  **Launch**:
    ```bash
    cd infra
    docker-compose up -d --build
    ```

4.  **Access**:
    -   **Frontend**: [http://localhost:5173](http://localhost:5173)
    -   **Backend API Docs**: [http://localhost:8000/docs](http://localhost:8000/docs)
